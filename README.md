## 三条线路怎么选

LightLayer 把网络分成三档，独服和云服务器共用同一套划分。选错线路，多花的钱基本白费。

**Premium 优化线路**走 CN2、CMIN2 这类路径，面向中国大陆，延迟低、晚高峰相对稳，代价是带宽小、单价高。香港那台 10M、洛杉矶那台 50M，说的都是优化线路的上限。建站、API、面向国内用户的后台系统，选这档。

**Standard 标准线路**在带宽和成本之间折中，国内访问比优化线路差一截，但比国际线路好。适合用户分布不确定、或者国内海外各占一半的业务。

**Global 国际线路**带宽最大、单价最低，走普通国际出口，国内访问会绕路，晚高峰可能波动。跑海外用户、大文件下载、备份、代理，选这档最划算。洛杉矶那台国际线路给到 300M，是三个档位里最宽的。

有一点需要说明：独服买的是整台机器，线路是在下单时选的，之后要换线路通常得提工单协商，不是后台点一下就切。所以下单前想清楚主要用户在哪儿。

公开的云服务器测评里，香港优化线路广东 ping 在 10 到 20ms、华北 40 到 50ms，洛杉矶优化线路国内三网在 150 到 170ms。这些是 VPS 的数据，独服走同一套线路资源，量级可以参考，但不等于独服实测结果。

**不提供无理由退款。** 官方的口径是机器故障或服务问题导致无法使用，可以申请退款或换机。觉得"用着不顺手"不属于理由。买之前先用官网提供的测试 IP 测一下线路，比事后扯皮省事。

## 独服还是 24.99 美元的 VPS

判断标准很清楚：你需要的东西 VPS 能不能给。

一台 1 核 1G、50G 硬盘的年付 VPS 是 24.99 美元/年，洛杉矶机型还给原生 IPv4。个人博客、小型展示站、API 测试、爬虫、轻量代理，这个配置完全够用，一年花不到一顿饭钱。香港、台湾、新加坡的同价机型是非原生 IP，跑流媒体解锁会受限。

需要往独服走的情况有这么几种：CPU 必须独享，不能和邻居抢；要扩几十个 IP 做站群；硬盘要 TB 级，VPS 的 50G 不够；要跑持续高负载的任务，比如视频转码、大数据处理、游戏服务端；或者业务已经稳定，不想再承受共享资源的性能波动。

反过来说，如果只是"想让网站快一点"，先看线路对不对，再考虑换机器类型。香港优化线路的 VPS 在国内访问上的表现，比洛杉矶国际线路的独服好得多，价格还便宜二十倍。

**优惠码在哪填？** 选好套餐加入购物车，结算页面有 Promo Code 输入框，填进去点验证。验证通过后价格会实时变化，看不到变化就是码失效了。

**能装 Windows 吗？** 可以，独服没有内存门槛。云服务器要 2G 内存以上才支持 Windows。

**流量超了会怎样？** 独服宣传的是不限流量，实际约束在带宽端口上，端口多大就跑多快，不存在超额停机。购买前确认所选线路的端口上限即可。

**能换 IP 吗？** 第一次免费，之后每次 2 到 5 美元。

**多久能拿到机器？** 独服 12 到 24 小时，VPS 5 到 10 分钟。
